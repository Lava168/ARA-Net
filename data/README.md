# Data Directory

This directory contains only public, synthetic, or aggregate demonstration inputs.

Raw ADNI, AIBL, OASIS, and IXI files are not redistributed. Users must obtain the original data from the respective data providers and map local paths in `configs/*.yaml`.

Included files:

- `example_metadata.csv`: tiny synthetic metadata table used by documentation and tests.
- `synthetic/`: optional public demo inputs generated by `scripts/prepare_features.py` and `scripts/train_base_models.py`.

Do not commit raw MRI, segmentation volumes, subject-level restricted exports, model checkpoints, or dataset-derived identifiers.
